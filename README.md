# Spendly – AI-Powered Expense Tracker

Spendly is an Android expense tracker designed to help users manage daily expenses, monitor monthly budgets, and understand their spending habits through visual summaries and statistics.

The application was built using an AI-assisted workflow, combining ChatGPT for prompt development, Google Stitch for UI/UX design, and Google AI Studio for application development.

## Features

- **Dashboard:** View the balance summary, monthly spending, remaining budget, and spending charts.
- **Expense Management:** Add, edit, and delete expense records.
- **Transaction History:** Search transactions and filter them by category or date.
- **Spending Analytics:** View category-wise spending and monthly trends.
- **Budget Management:** Set a monthly budget and track spending against it.
- **Automatic Calculations:** Update spending totals and budget figures when transactions change.
- **Local Data Storage:** Designed to retain expense data on the device between app sessions.
- **Mobile Navigation:** Navigate between Dashboard, Expenses, Add Expense, and Statistics.
- **Responsive UI:** Designed for a clean and intuitive Android mobile experience.

## Technology Stack and Tools

- **ChatGPT:** Prompt creation, refinement, and development planning.
- **Google Stitch:** AI-assisted UI/UX design and screen generation.
- **Google AI Studio:** AI-assisted application development and code generation.
- **Android:** Mobile application platform.
- **Git and GitHub:** Source code version control and project documentation.

## Development Workflow

1. Defined the app concept and features with assistance from ChatGPT.
2. Generated the mobile interface using Google Stitch.
3. Exported the generated design to Google AI Studio.
4. Used a detailed prompt to generate the Android application and implement the requested functionality.
5. Prepared an Android device by enabling Developer options and USB debugging.
6. Connected the phone to a laptop via USB and installed the generated application.
7. Opened and tested the app on the physical Android device.
